# Chuffed To Bits

Image to Minecraft painting converter that runs entirely in your browser.
Center-crops to aspect, pixelizes to the 16-64px painting grid, adds a
1px border, and exports a PNG.

Unofficial fan project. Not affiliated with, endorsed by, or connected to
Mumbo Jumbo or Mojang.

## Shortcuts

`O` open · `S` save · `E` export upscaled · `I` pick border color ·
`C` adjust crop · `G` pixel grid · `+`/`-` zoom · `Esc` leave crop/picker ·
`←`/`→` previous/next image in batch
